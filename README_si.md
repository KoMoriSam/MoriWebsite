## මෙතැනින් අරඹන්න

## කියවීම සහ සාකච්ඡා

බ්ලොග් ලිපි සහ නවකතාව සඳහා පටුන, කියවීමේ ප්‍රගතිය සහ පිරිසැලසුම් සැකසුම් ඇත. තේමාව, කියවූ ස්ථානය සහ කියවීමේ මනාප වත්මන් බ්‍රව්සරයේ සුරැකෙන බැවින් පසුව එතැනින් ඉදිරියට කියවිය හැක. ලිපිවල කේත, ගණිත සූත්‍ර, රූප සටහන්, පාදසටහන් හා ruby උච්චාරණ සටහන් පෙන්වන අතර කේත කොටස් පිටපත් කළ හැක.

`Ctrl + K` යතුරු ඔබා (macOS සඳහා `Cmd + K`) වෙබ් අඩවියේ සෙවුම විවෘත කරන්න. ලිපි කොටස්, නවකතා පරිච්ඡේද, අනුවාද වෙනස්කම් සහ බලපත්‍ර සටහන් සෙවිය හැක. අන්තර්ගත වර්ගය, ටැග්, වෙළුම් හෝ වර්ෂ අනුව පෙරහන් යොදා අදාළ තැනට කෙළින්ම යා හැක.

අතුරුමුහුණත චීන, ඉංග්‍රීසි, ප්‍රංශ සහ සිංහල භාෂාවලින් ඇත. බ්ලොග් ලිපියකට පවතින පරිවර්තන අතර මාරු විය හැක. තෝරාගත් භාෂාව නොමැති විට පවතින අනුවාදයක් සහ භාෂාව පිළිබඳ දැනුම්දීමක් පෙන්වයි.

නවකතාවේ පටුන පොදුවේ බැලිය හැකි අතර පරිච්ඡේද කියවීමට GitHub හරහා පිවිසීම අවශ්‍ය වේ. Giscus මඟින් ලිපි, පරිච්ඡේද සහ තනි ඡේද පිළිබඳ සාකච්ඡා කළ හැක; අදහස් පළ කිරීමට GitHub ගිණුමක් අවශ්‍ය වේ. බ්ලොග් සහ නවකතා අදහස් පිළිවෙළින් [theWake](https://github.com/KoMoriSam/theWake) හා [theHorizon](https://github.com/KoMoriSam/theHorizon) හි GitHub Discussions තුළ පවතී.

## මෙවලම් සහ ක්‍රීඩා

**රූප පරිවර්තකය** රූප බ්‍රව්සරය තුළ සකසයි. රූප සමූහයක් සූදානම් කිරීම, ගොනු ප්‍රමාණ අඩු කිරීම, මාන එකසේ සැකසීම, පෙළ හෝ රූප දිය සලකුණු යෙදීම සහ සජීවී රූප සැකසීම සඳහා භාවිත කළ හැක.

**සිංහල අකුරු කේතන පරිවර්තකය** Unicode සහ පැරණි අකුරු කේතන අතර පරිවර්තනය කරයි. පෙළ කෙළින්ම ඇලවීමට හෝ DOCX සහ PPTX ගොනු සැකසීමට හැකිය. තෝරාගත හැකි පෙළ සහිත PDF ගොනුවක අන්තර්ගතය සංස්කරණය කළ හැකි DOCX ගොනුවක් ලෙසත්, පිටු සැකැස්ම සංස්කරණය කළ හැකි PPTX ගොනුවක් ලෙසත් අපනයනය කළ හැකිය.

**බහු ක්‍රීඩක පුවරු ක්‍රීඩා** සඳහා කාමර කේතයක් හෝ ආරාධනා සබැඳියක් මඟින් මිතුරන් එකම කාමරයට එක් කරගත හැක. Avalon හි චරිත සැකසීම, කණ්ඩායම් ඡන්දය, මෙහෙයුම් හා තරග වාර්තා ඇත. ## දේශීයව ධාවනය කිරීම

ව්‍යාපෘතිය Vue 3, Vite SSG, Tailwind CSS, daisyUI සහ Pagefind භාවිත කරයි. සේවාදායක API Cloudflare Workers මත ක්‍රියාත්මක වේ. Node.js 24.15 හෝ ඊට පසු 24.x අනුවාදයක්, නැතහොත් Node.js 26 හෝ ඊට පසු අනුවාදයක් සහ pnpm 12.3.4 අවශ්‍ය වේ.

```bash
git clone https://github.com/KoMoriSam/MoriWebsite.git
cd MoriWebsite
pnpm install
```

ව්‍යාපෘතියේ මූලයේ `.env.development` සාදා අන්තර්ගත සහ අදහස් තේමා ලිපින සකසන්න:

```dotenv
VITE_BLOG_RAW=https://raw.komori.cc/post
VITE_NOVEL_RAW=https://raw.komori.cc/novel
VITE_GISCUS_CSS_RAW=https://raw.komori.cc/giscus
```

```bash
pnpm dev
```

Workers Builds අවසන් වරට සාර්ථකව ප්‍රකාශ කළ build එකේ සැණරුව යළි ලබා ගනී. අන්තර්ගතය පමණක් වෙනස් වී සැණරුව ගැළපේ නම්, වර්ධක SSG මඟින් අදාළ පිටු සහ සම්පත් යළි සාදා කලින් ගොඩනැඟූ වෙබ් කේතය භාවිත කරයි. වෙබ් කේතය හෝ build සැකසුම් වෙනස් වී ඇත්නම්, නැතිනම් සැණරුව භාවිත කළ නොහැකි නම්, සම්පූර්ණ build එකක් සිදු වේ. ප්‍රකාශ කිරීමට වෙනසක් නැති විට ප්‍රකාශනය මඟ හැරේ. Build ආකාර දෙකේදීම හැඹිලියේ ඇති වලංගු රූප ප්‍රභේද යළි භාවිත වේ. Build සටහනේ ප්‍රතිඵලය `INCREMENTAL`, `FULL` හෝ `SKIPPED` ලෙස දැක්වේ.

වර්ධක ප්‍රකාශනයකදී යොදවන්නේ ගොනු වෙනස් වූ Worker පමණි. වෙබ් අඩවිය සහ අන්තර්ගතය සපයන්නේ Workers Static Assets මඟිනි. පෞද්ගලික R2 බාල්දිය භාවිත වන්නේ build සැණරූ තබාගැනීමට පමණි. බ්ලොග් සහ නවකතාවේ පෙළ හා රූප `raw.komori.cc/post` සහ `raw.komori.cc/novel` ඔස්සේ ලබා ගත හැකිය. එම වසමේම `/kaiming` මඟින් අකුරුත්, `/giscus` මඟින් අදහස් තේමාත්, `/giscus/images/spin.gif` මඟින් පැටවීමේ සජීවී රූපයත් සපයයි.

`website` සඳහා Workers Builds සැකසුම්වල `production` ශාඛාව තෝරන්න. Build command හිස්ව තබා Deploy command ලෙස `pnpm run build:smart --deploy` යොදන්න. පහත විචල්‍ය නිෂ්පාදන build පරිසරයට එක් කරන්න:
