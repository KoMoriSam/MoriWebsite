## 功能

- 更新首页布局与内容展示
- 新增 Pixabay API 接口，支持随机背景图功能
- 新增工具页
- 为博客文章补充阅读位置跟踪功能
- 小说详情页新增「最新章节」快捷跳转按钮

## 改进

- 新增 Fraunces 斜体字形，完善西文排版
- 增强段落 ID 处理，优化滚动和哈希同步逻辑
- 优化章节和博客文章的路由与永久链接结构，提升 URL 可读性
- 优化标题和段落排版效果

## 修复

- 修复 API 基础地址的域名错误
- 修复 ChapterInfo 组件中 badge 和 content 属性非必需时的类型警告
- 修复 ArticleReader 仅在文章未加载时显示底部导航栏的问题
- 修复不同页面间阅读进度共享导致位置错乱的问题

## 重构

- 重构路由，合并关于和联系页面至主页，删除独立页面（About / Contact）

## 维护

- 移除 package.json 中不必要的脚本命令
- 更新 tailwindcss，daisyui 及 remixicon 版本

## 升级前请注意

本版本移除独立的 `/about` 与 `/contact` 页面，旧地址不再兼容。调整博客和小说的永久链接结构，兼容旧的查询格式。
