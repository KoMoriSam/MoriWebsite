## 功能

- Markdown 内容支持聊天气泡和动态内容等展示形式
- 评论区新增四种配色，可适配明暗主题

## 改进

- 更新字体引入方式，优化加载性能
- 优化服务器信息的排版，新增城市图标并调整版本号位置
- 朱雀仿宋字体优先回落至霞鹜新晰宋，提升字体渲染兼容性
- 优化 Markdown 内容样式及排版（标题、段落、Alert 警告框、列表项）
- 优化服务器地址提示信息及样式
- 调整代码块排版及样式

## 修复

- 修复部分页面样式显示异常，并恢复旧版网页的存档入口
- 恢复旧版网页链接新标签页打开行为
- 修复段落关闭时隐藏的按钮渲染问题

- 加强网站请求凭据保护，降低敏感信息意外暴露的风险
