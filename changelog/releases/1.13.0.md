## 功能

- 新增 Markdown 动态内容与评论渲染能力
- 新增 Giscus 自定义主题，四套配色分别适配 daisyUI 的 lemonade（默认日间）、forest（默认夜间）、corporate（日间模式）、dim（夜间模式）

## 改进

- 更新字体引入方式，优化加载性能
- 优化服务器信息组件排版及样式（新增城市图标、调整版本号位置）
- 朱雀仿宋字体优先回落至霞鹜新晰宋，提升字体渲染兼容性
- 优化 Markdown 内容样式及排版（标题、段落、Alert 警告框、列表项）
- 优化服务器地址提示信息及样式
- 调整代码块排版及样式

## 修复

- 修复错误的全局 CSS 样式
- 恢复迁移中遗漏的环境配置、素材和存档页
- 恢复旧版网页链接新标签页打开行为
- 修复段落关闭时隐藏的按钮渲染问题

## 重构

- 集中管理 Giscus 仓库与评论分类配置
- 归纳图标样式至 main.css 统一管理
