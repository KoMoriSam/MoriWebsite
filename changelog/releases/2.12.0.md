## 功能

- 扩展阅读器背景预设，支持将预设图片（非自定义）设置为阅读背景

## 改进

- 统一脚注、提示块、预览背景和图标过渡样式
- Markdown 支持 figure 图注渲染，支持 wikilink 图片引用并适配 SVG 明暗主题
- 优化章节标题与统计信息布局
- 支持按评论数动态挂载段评入口
- 统一 Markdown 链接样式

## 修复

- 修复 SSR 环境下 Mermaid 视图模式与渲染状态逻辑
- 修复 LaTeX SVG 渲染问题，稳定正文与分享卡片的 LaTeX 字号
- 加强 Markdown 渲染的 XSS 防护
- 修复 Mermaid 图表分享捕获与代码块 data-language 属性绑定
- 更换外链图标源，支持分享卡片显示外链图标

## 重构

- 统一代码块与 Mermaid 的顶栏和代码展示功能
- 重构自定义容器组件与移动分页适配
