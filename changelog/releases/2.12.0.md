## 功能

- 扩展阅读器背景预设，支持将预设图片（非自定义）设置为阅读背景

## 改进

- 统一脚注、提示块、预览背景和图标过渡样式
- Markdown 支持 figure 图注渲染，支持 wikilink 图片引用并适配 SVG 明暗主题
- 优化章节标题与统计信息布局
- 评论较多时按需显示段落评论入口
- 统一 Markdown 链接样式

## 修复

- 修复 Mermaid 图表视图切换和 LaTeX 公式显示异常
- 加强 Markdown 内容安全处理，降低恶意内容造成风险的可能
- 修复分享卡片未能完整显示 Mermaid 图表的问题
- 分享卡片现在可以正确显示外部链接图标
