## 功能

- 新增段评数量接口，支持从 GitHub Discussions 获取段落评论计数
- 新增 markdown-it-mark 插件，支持 <mark> / == 高亮标记语法

## 改进

- 统一 Giscus 评论区与主站字体
- 调整代码块样式并添加段落评论计数样式
- 调整段落评论的按钮图标与交互样式
- 调整并优化 Markdown 相关样式

## 修复

- 修复 Giscus 在博客页面创建新评论失效的问题
- 修复 Giscus 在网络不佳时加载失败的问题，并支持动态重载
- 修复渲染插件 markdown-it-alert 对子元素进行两次解析的问题
- 修复脚注等样式在 Callout 及聊天容器内渲染失效的问题
- 修复段评标题过滤与内容识别异常

## 优化

- 支持按需加载代码高亮语言，减少初始资源体积

## 重构

- 重构 Giscus 配置结构，新增主题映射、mappings 和 configs 分组，提升可维护性
- 优化章节和位置跟踪逻辑，更新路由配置
- 重构聊天和动态内容渲染插件（markdown-it-chat），优化代码结构与可读性
- 优化段落评论的 ID 生成与状态管理

## 维护

- 整理组件目录结构（articles → blog/reader），提高可维护性
- 更新网站图标
- 清理废弃的 SVG 文件
