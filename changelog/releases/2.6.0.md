## 功能

- 重构移动端阅读控制，新增更多操作与排版自定义功能
- 抽出独立阅读控制栏、状态栏与弹窗组件，简化交互逻辑
- 新增音量键翻页（不完全支持）、滚轮翻页与九宫格点击区域自定义
- 新增阅读布局预设（保存 / 应用 / 删除 / 重置）与多套颜色主题
- 新增长按文本上下文菜单，支持复制、全文搜索与段落评论
- 书内搜索支持初始关键词与历史记录替换导航

## 改进

- 优化移动端阅读排版与颜色主题，提升阅读体验
- 优化阅读器相关样式与组件结构
- 优化阅读位置追踪，支持按视口保存与精确恢复，模式切换时保持阅读位置
- 改进移动端目录手势、阅读进度条、章节控制和文章翻页交互
- 调整阅读器样式、导航入口及测试展示页面
- 优化阅读器相关组件与样式结构

## 修复

- 统一模态框关闭与浏览器返回历史处理，避免关闭弹窗时发生路由和滚动跳转
- 修复阅读模式切换时的位置错乱问题

## 重构

- 重构移动端分页 / 滚动阅读器，抽出分页测量、脚注布局、章节过渡与阅读位置等模块
- 导航栏改为事件驱动显隐，简化交互逻辑
- 段落评论支持事件驱动打开，聊天栏气泡拆分为独立分页块
- 继续解耦阅读器组件，移除旧 ReaderShell、抽屉及重复的移动端排版组件
- 将提示块、聊天、朋友圈和代码块迁移为可挂载的 Vue Markdown 组件，统一跨端渲染
- 统一跨端排版与 Markdown 渲染逻辑
