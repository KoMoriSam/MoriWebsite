## 功能

- 新增开明标点字体页面，展示字体规格、特性与下载链接
- 抽象代码块组件，支持动态挂载与卸载，优化代码高亮加载
- 增强聊天消息渲染，支持仅渲染消息模式，优化插件调用逻辑

## 改进

- 重构字体选择器，调整段落高度与行间距默认值，优化阅读排版
- 优化更新详情组件的布局和样式，调整变更项展示方式
- 优化代码块组件样式，调整语言标签与复制按钮
- 优化模态框组件，新增取消按钮与确认模式，滚动条更改为细滚动条，优化标题和描述的渲染方式，支持前置操作插槽
- 优化 Toast 组件样式与层级关系
- 更新段落评论标题样式，调整标题和内容的类名以提升可读性
- 统一页面内边距，优化搜索框与分页菜单的视觉效果
- 改用语义化标签组织内容页结构
- 移除不必要的 KeepAlive 与 client-only 标签，简化模板结构

## 修复

- 在剪贴板 API 不可用时回退到兼容的代码复制方式
- 修复代码块 hljs 代码高亮无效的问题
- 修复代码块 props.code 丢失响应性的问题

## 重构

- 重构导航组件，提升页面导航的可维护性
- 解耦分页组件与章节控制器，简化组件依赖关系

## 维护

- 扩充开发环境测试入口和组件测试场景
- 将 Kaiming 字体迁移至在线资源
- 合并并清理代码块冗余样式，规范样式结构
- 整理测试用例并优化相关组件交互
