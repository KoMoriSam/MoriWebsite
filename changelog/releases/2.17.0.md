本次更新接入已 GitHub 登录，统一账户、通知、语言和主题设置入口。继续完善了阿瓦隆的玩法说明和对局界面。

## 功能

- 复用 Giscus 授权接入 GitHub 登录与退出，显示 GitHub 账户名称、头像和公开邮箱，并同步登录及会话状态
- 在导航栏增加账户入口，集中展示账户信息、通知中心、语言和主题设置
- 小说章节阅读、全文搜索及相关入口在站内界面中要求先登录，登录后可回到原来的页面和阅读位置
- 将公共搜索与小说搜索索引分开，游客只加载公共内容；登录后按需显示小说结果，退出或会话失效时清除小说搜索数据
- 游戏房间支持使用自定义昵称或 GitHub 名称与头像，大厅可编辑自己的资料，资料变化同步给房间并重新进入准备流程

## 改进

-
- 阿瓦隆规则书改为可逐步查看的玩法指南，展示夜晚、议事、组队、表决、任务和结算流程
- 统一阿瓦隆任务进度、角色预览和大厅配置展示，完善侧栏讨论计时、结束操作及发言区域布局

## 重构

- 按业务和职责整理组件、composable 及工具文件的目录与命名，同步更新引用和检查脚本

## 版本说明

游戏中的 GitHub 名称和头像仅用于展示，房间接口不接收 Giscus 会话或 GitHub 令牌。
