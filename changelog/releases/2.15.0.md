本次更新以僧伽罗字体编码转换器的大幅升级为重点，同时改进字体选择、Markdown 代码块和多个页面的阅读体验。

## 功能

- 新增文档模式，可读取 DOCX 和含可选择文本的 PDF，识别源编码后转换并下载 DOCX；识别不准确时可手动切换方向
- 文本模式支持将 Unicode 或 Legacy 转换结果直接下载为 DOCX，并增加源编码识别与切换提示
- 新增 Unicode 和 Legacy 字体选择、字形预览及加粗控制；Legacy 区域可切换查看底层编码并直接编辑字形文本
- 增加转换选项，可按需要处理合写字、相接字母、රකාරාංශය、රේඵය 等字形形式
- 字体选择器新增搜索和字形预览，支持在网站字体、上传字体及可用设备字体中查找；组件可按页面需要使用不同尺寸
- Markdown 围栏代码块支持设置标题，代码块顶部可显示指定标题

## 改进

- 重构双向转换规则，改进元音附标、合写字与特殊字形的处理，并尽量保留混排文本中的英文、数字和标点
- 更新 Abhaya、Gemunu 等预览字体和字体生成资源，补充编码示例、使用说明及第三方授权信息
- 优化双栏布局、复制粘贴、交换方向和文本区域交互，方便对照字形与实际编码
- 调整小说详情页的章节目录和评论区域布局，优化章节列表、加载占位和窄屏操作按钮排列
- 调整公告徽章、标题与通知中心的排版，使状态标识更清晰
- 统一内容页标题、元信息和操作区的布局，并微调图片转换器、服务器状态等页面的排版

## 维护

- 新增站点 SVG 图标

## 版本说明

文档模式仅提取文件中的可选择文本，暂不保留原文档排版，也不支持扫描版 PDF 的文字识别；导出格式为 DOCX。转换结果建议结合所用字体检查。
