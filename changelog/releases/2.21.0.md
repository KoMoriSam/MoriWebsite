## 功能

- 文章页提供相关文章推荐，并显示文章修改时间；内容可能过时时会提醒读者核对最新信息
- 正文中的相关文章、标题和段落可直接访问，GitHub 项目与相关文章也可查看预览卡片
- 评论区改用与网站整合的界面展示和接口，评论仍存储在 GitHub Discussions

## 改进

- 分享文章时能更完整地保留排版、表格、媒体与链接卡片，长内容的预览和生成也更顺畅
- Mermaid 渲染由原生渲染器换用 Pele 渲染器，渲染速度加快，图表结构和大小更能适应显示区域
- RSS 正文支持更多常用 Markdown 格式
- 页面交互响应更及时，通知、跳转反馈和小说详情显示更加清楚
- 僧伽罗文档转换能更准确地保持跨段文字的顺序

## 修复

- 修复页面加载时的闪动和布局跳动，以及不同屏幕下博客卡片显示不一致的问题
- 修正部分多语言界面文字
