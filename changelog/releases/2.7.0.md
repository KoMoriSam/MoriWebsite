## 功能

- 扩展站点主题选择，并可在阅读设置中切换站点主题
- 重构代码块并适配主题高亮，支持多套主题配色
- 统一跨端文本选择与长按操作菜单，优化选中文本交互
- 扩展标题、列表与章节头的段落评论支持，抽象出评论触发器组件
- 新增志莽行书和更纱黑体斜体选项

## 改进

- 将朱雀仿宋迁移至 CDN，改善字体加载
- 调整段落签名的内边距与外边距样式
- 使用 Inter 与 Petrona 替换原有西文字体，优化西文排版
- 更新阅读器字体选项、签名排版与测试示例

## 修复

- 修复移动端目录无法随滚动方向正确切换状态的问题
- 修复文章翻页导航的布局问题

## 重构

- 集中管理中文、拉丁文与僧伽罗文字体加载

## 维护

- 移除旧字体入口与重复的远程样式引入
- 完善字体来源与许可证说明，区分 OFL、IPA Font License 与 Apache 许可
