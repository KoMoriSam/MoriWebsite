## 功能

- 僧伽罗字体编码转换器的文档模式支持 PPTX 格式
- 含可选中文字的 PDF 可按内容导出可编辑 DOCX，或按页面版式导出 PPTX；可选择导出方式，转换时尽量保留段落、图片和页面布局

## 改进

- 重新设计首页，集中展示个人介绍、图片、近期文章、工具、游戏和项目
- 统一导航、页脚、内容卡片、小说与游戏入口及开明字体页面的视觉和操作方式
- 第三方声明页面补充僧伽罗语内容

## 修复

- 修正 Markdown 表格在不同屏宽下的换行与宽度适配
- 修正全站僧伽罗语数量表达的语序和单复数形式
- 完善文档转换中的僧伽罗语字形映射和版式处理，减少特殊字符与复杂页面的转换问题

## 优化

- 优化首页图片加载、背景效果与页面动效
- 改进 GitHub 公开资料的缓存和失败回退
