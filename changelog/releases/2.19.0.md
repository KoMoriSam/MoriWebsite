## 功能

- 博客支持为同一篇文章提供中文、英文和僧伽罗语版本；文章页可切换已有译文，站点语言切换也会同步选择对应版本，旧文章链接继续可用
- 缺少当前语言的译文时显示实际采用的语言：僧伽罗语优先回退英语，再回退原文；明确指定语言的文章链接不会悄悄跳到其他版本
- 机翻译文显示提示并可直接跳转原文；译文页面、搜索索引与 SEO 信息按语言生成，RSS 保持每篇文章一条原文记录

## 改进

- 游戏房间和阿瓦隆对局统一展示玩家头像、在线与提交进度，调整大厅、讨论、任务和移动端操作布局
- 工具与游戏列表统一封面卡片、加载状态和数量信息，首页工具入口也采用相应封面
- 博客与小说阅读器在加载、登录检查期间显示与页面布局一致的占位内容
- 路由跳转增加加载、失败与重试提示
- 调整账户中心的语言、主题和通知操作
- 调整站内 Toast、章节标题和滚动边缘提示的布局
- 整理僧伽罗转换器的示例、辅音简写对照与多语言说明

## 修复

- 修正僧伽罗传统字体编码中部分非标准拼写、合写形式和元音组合的转换，并完善相关控制选项与字体显示
- 修复 GitHub 资料请求失败或限流后身份显示和重试状态异常，改进资料不可用时的提示
- 修复 Markdown 正文中的自定义样式未加载、行内属性解析兼容性，以及列表提示换行和 Ruby 注音边界的显示问题
- 修复阅读器脚注跳转触发导航加载态与滚动冲突，并调整账户控制器焦点和通知列表裁切

## 优化

- 将博客正文从客户端路由元数据中拆出，按页面恢复静态快照；站点资源按需加载并清理构建产物中的未使用文件
- 将博客、小说头像及 Markdown 图片资源交由各自内容源的清单管理，按可用的图片版本加载并保留默认头像回退
