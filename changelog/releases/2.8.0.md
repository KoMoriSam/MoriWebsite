## 功能

- 新增僧伽罗语字体转换器，支持 Unicode 与 ASCII 传统编码互转及实时输入输出，并附有 Unicode 与 ASCII 编码差异的说明信息
- 新增 Abhaya Libre 字体选项，改善传统文字显示
- 内容页新增面包屑导航，优化标题样式
- 工具页增强为展示可用工具列表，附带描述与图标
- 新增 Gemunu Libre 字体选项，改善传统文字显示

## 改进

- 优化首页视图，新增指向新工具的入口链接
- 改善内容页与文章阅读器的布局
- 统一僧伽罗语转换器的 ASCII 编码术语并优化布局
- 调整 Sinhala Sangam MN 字体比例，改善僧伽罗语显示
- 优化小说详情页图像加载占位符的首屏表现

## 修复

- 修复阅读页上下篇按钮、文章封面和 Markdown 内容显示异常
