## 功能

- 新增僧伽罗语字体转换器，支持 Unicode 与 ASCII 传统编码互转及实时输入输出，并附有 Unicode 与 ASCII 编码差异的说明信息
- 新增 Abhaya Libre 字体显示，并生成模拟 FM Abhaya 显示的兼容字体
- 内容页新增面包屑导航，优化标题样式
- 工具页增强为展示可用工具列表，附带描述与图标
- 新增 Gemunu Libre 兼容字体，用于模拟 FM Gemunu 显示

## 改进

- 优化首页视图，新增指向新工具的入口链接
- 调整 ContentPage 与文章阅读器组件样式以改善布局
- 统一僧伽罗语转换器的 ASCII 编码术语并优化布局
- 调整 Sinhala Sangam MN 字体比例，改善僧伽罗语显示
- 优化小说详情页图像加载占位符的首屏表现

## 修复

- 修复阅读页上下篇按钮 SSR 阶段不渲染的问题，文章路由元信息补充文章列表
- 修复一些 Markdown 组件 SSR 与客户端渲染不一致的问题
- 修复 SSG 预渲染页面推文封面图不显示遮罩的问题，保留左右栏空位作为边距

## 重构

- 精简不必要的客户端渲染边界

## 维护

- 扩展兼容字体生成脚本，支持 Abhaya Libre 与 Gemunu Libre
- 新增字体源文件与生成产物，更新相关说明文档
- 更新第三方声明，新增 @fontsource/gemunu-libre 依赖
