## 功能

- 新增基于 Cloudflare D1 的访问与阅读统计，支持批量查询内容阅读统计
- Markdown 公式改用 MathJax SVG 渲染，支持 LaTeX 复制与分享卡片渲染
- 展示文章与章节的阅读评论统计，汇总内容主评论、段评与回复
- 分享卡片新增阅读评论统计展示
- 新增独立的 API Worker 部署配置

## 改进

- 增强二维码可见性并优化分享链接生成
- 优化分享卡片对话框和跨书写系统文本换行
- 统一系统主题名称和僧伽罗语编码术语
- 优化分页组件与文章列表的结构和样式
- 调整站点统计与社交链接顺序、博客文章列表页面包屑导航信息

## 修复

- 修复桌面端小说阅读位置恢复失效的问题
- 修复分享卡片中聊天容器、引用块、动态容器、脚注正文与列表重复渲染的问题
- 修复 LaTeX 首次加载不渲染的问题

## 维护
