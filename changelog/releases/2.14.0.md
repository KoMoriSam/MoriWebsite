## 功能

- 新增浏览器端批量图片转换工具，支持队列处理、格式转换、尺寸与质量调整、动画预览以及文字、图片和图标水印
- 新增全站公告系统，支持远端即时发布、未读状态、置顶公告、重要公告提醒、公告中心和历史页面
- 新增博客 RSS 2.0 Feed，提供最近公开推文的摘要、标签、永久链接和经过清洗的完整正文
- 新增由单版本 Markdown 驱动的更新日志系统，支持静态快照、远端即时修订、历史分组、搜索与版本锚点
- 新增 Git 标签驱动的自动发布流程，在网站部署成功后依次同步更新日志和公告数据
- 新增通用 Markdown 标准模式，支持原生 HTML、代码块、提示块及可配置的 prose 尺寸
- 新增统一的阅读字体选择能力，改善正文与工具页面在不同文字环境下的字体适配

## 改进

- 优化公告中心与公告页面的骨架屏、未读优先排序、统一徽标以及多层级重要公告弹窗交互
- 优化更新日志的年份折叠、远端覆盖与静态回退逻辑，并让搜索和锚点跳转自动展开目标年份
- 优化 Markdown 代码块和提示块的字号与内外边距，使其能够随 prose 尺寸同步缩放
- 优化僧伽罗语字体转换器的响应式布局、等高输入区域、交换操作、复制反馈与语义配色
- 优化主题选择器和导航公告面板在窄屏设备上的尺寸、位置与内部响应式排列
- 优化内容页留白、页脚置底、表格和脚注排版，并根据背景图自动调整移动端阅读配色

## 修复

- 修复阅读器触屏长按特殊元素、图片预览右键菜单、图片段评和 SVG 主题适配问题
- 修复分享卡片未完整捕获正文图片，以及评论元数据遗漏回复数量的问题

## 优化

- 优化首屏资源分块、字体样式体积和搜索数据加载，降低不必要的初始资源开销

## 重构

- 将旧版更新提示迁移为根级公告覆盖层，统一复用站点 Modal、Markdown 渲染和 HTML 清洗链路
- 将 60 条历史更新日志按严格 SemVer 整理为 39 个真实发布批次，并将最新正式版本重排为 2.13.0
- 重构公告与更新日志 CLI，分离本地发布准备和远端 KV 写入，并为失败操作保留备份与回滚能力

## 维护

- 更新 daisyUI 依赖并补充 pnpm workspace 配置
- 移除旧的 `cl-pages` 强制推送和 GitHub Pages 发布依赖，改用 Wrangler 与 GitHub Actions 发布网站
